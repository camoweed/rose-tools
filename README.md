# Rose Tools

Rose Tools is a mod designed for RoseSMP which adds a new tier of utility tools.
Rose tier tools require steel, algae, and roses to craft.

### Rose Axe
Has the effect of treecapitator.

### Rose Pickaxe
Has the effect of veinminer on ores and moss.

### Rose Sword
Small healing effect.

### Rose Armour
High fall resistance, similar to leather but much higher durability.
